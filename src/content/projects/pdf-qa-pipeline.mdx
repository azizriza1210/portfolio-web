## Overview

A pipeline that takes any PDF document, extracts and chunks its text, generates embeddings, and provides a Q&A interface with cited page references.

## Pipeline Steps

1. **Ingest** — Parse PDFs with PyPDF2 and pdfplumber
2. **Chunk** — Recursive text splitting with overlap
3. **Embed** — OpenAI `text-embedding-3-small`
4. **Store** — ChromaDB for local, Pinecone for production
5. **Query** — Semantic search + LLM answer generation

## Results

Processed 500+ pages across 12 PDFs. Average query latency under 2 seconds. Citation accuracy at 94%.
